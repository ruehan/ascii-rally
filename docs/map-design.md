## 1. 콘셉트

조용한 언덕 지대에서 열리는 **한 개발자의 랠리 시즌**.
서비스 파크에서 출발 → 북쪽 언덕을 넘으면 프로젝트마다 하나씩인 짧은 자갈길 스페셜 스테이지가 부챗살처럼 펼쳐짐 → 완주하면 기록과 함께 프로젝트 README가 열림.

- **모터스포츠 요소** = 구조와 어휘: 스테이지, 24시간 내구 루프, 서킷, 피트월
- **개발자 요소** = 정보 표현 방식: 터미널 HUD, 코드라이버 페이스노트 로그, git log 형식 리더보드, `01` 바닥 패드
- **Over the Hill 분위기** = 등고선 지도 같은 지형, 흙·올리브 파스텔 색, 넓은 여백

## 5. 24H 루프와 낮/밤

루프 거리 → 시각. 1시간 ≈ 4.5초, 한 바퀴 ~110초.

| 구간 | 시각 | 지형 | 경력 |
|---|---|---|---|
| 출발 (-40,160) | 15:00 | 서쪽 출발 | 시작 (학업, 첫 커밋) |
| 서쪽 | 15→20시 노을 | 북쪽 오르막 | 초기 경력 |
| 북쪽 능선 | 20→02시 밤 | 동쪽 | 성장기 |
| 동쪽 300m 직선 | 02→06시 한밤→여명 | 남쪽 내리막 (직선이라 안전) | 밤의 긴 직선 = 내구 레이스 오마주 |
| 남쪽 | 06→15시 새벽→낮 | 서쪽 | 돌파 → 현재. 결승 = "now" |

- **세션**: 출발선을 서쪽으로 지나야 시계 시작. 루프에서 25m 이상 벗어나면 `session paused` → 3초에 걸쳐 기본 "늦은 오후"로 복귀
- **밤의 ASCII**: 태양 끔, 하늘광 최소 → 대부분 공백. **헤드라이트 원뿔 안만 글자로 채워짐**. 윤곽선 희미하게 (`edgeGain` 0.3). 마일스톤 보드와 반사판(10m 간격)이 GOLD 점으로 길잡이
- **밝기 보정**: `lum = lum × exposure + lumFloor` (밤 exposure 2.5, floor 0.06) — 지면이 성긴 `.` 로 남음
- **배경**은 터미널 느낌 위해 항상 어둡게 (낮 #0b0d0a, 노을 #140c08, 밤 #020308). 시간대는 태양색 색조로 표현

## 7. 가독성 규칙 (지형 포함)

1. **지형은 거의 차를 안 가림**: 카메라 시선 기울기 1:1 → 경사 45° 미만 지형은 차를 가리지 않음. 주행 경사 ≤25%, 길 밖 ≤40%. 언덕 절대 높이는 제한 없음
2. **실제로 가리는 건 소품**: 내리막 트레일 남쪽 8m 이내 소품 ≤2.5m. 나무는 트레일 북쪽 또는 8m 밖
3. **앞 시야 = `9.4 / (0.414 + 경사)`**: 평지 22m · 오르막 10% 18m · 25% 14m · 내리막 25% 57m. 스테이지는 "오르막 → 언덕 꼭대기 → 내리막 공개" 리듬
4. **등고선**: 2m마다 가는 선, 10m마다 굵은 선. 평지엔 선 없음 → **평평한 곳 = 조용한 곳 = 패드** 로 자연스럽게 읽힘
5. **밝기 순서**: 바닥 0.15~0.25 · 등고선 0.3 · 트레일 0.4 · 물체 0.5+ · 랜드마크 0.7+
6. **트레일 대비**: 문자세트 전환 (`.,-` → `.:;`) + 밝기. 스테이지 양옆 10m마다 0.6m 빨강/흰 마커 기둥
7. **높이 띠 경계** 6m, 14m. 등고선과 1m 어긋나게
8. v1 규칙 유지: 최소 두께 0.6m, 각진 도형, 구역당 대표색 하나, 조형물은 남쪽(카메라 쪽) 향하게

## 8. 기술 설계

### 지형 — 노이즈 + 선언형 피처를 미리 구운 높이 격자

- `src/world/terrain.js` (three 없는 순수 JS, 노드 테스트 가능): 시드 기반 노이즈 위에 `map.js` 피처를 찍어 `Float32Array` 격자로 한 번 구움
- **화면 메시, 물리, 나중의 Rapier가 같은 배열을 읽음** → 차가 뜨거나 묻히는 오차가 구조적으로 없음
- 크기 **400m × 400m (±200), 2m 격자** → 201² ≈ 4만 정점, 분할 렌더링 불필요
- `heightAt` 은 메시와 같은 삼각형 분할로 보간

```js
// map.js
terrain: {
  size: 400, cell: 2, seed: 7,
  base: { amp: 1.5, wavelength: 50 },
  features: [
    { type: 'ridge',  points: [[-100, 85], [100, 85]], height: 9, width: 30 },
    { type: 'hill',   pos: [-130, 55], r: 30, height: 22 },
    { type: 'trail',  points: [[0, 135], [0, 85], [0, 30]], width: 6, smooth: 20, surface: 'gravel' },
    { type: 'crest',  on: 'ss3', at: 70, length: 20, height: 3.5 },
    { type: 'flat',   poly: [/* circuit */], y: 1, surface: 'asphalt' },
    { type: 'pad',    pos: [0, 125], r: 22 },   // 구역 패드는 build.js가 자동 생성
  ],
},
trails: [{ id, points, width, surface }],
stages: [{ id, project, trail, splits, notes, target }],
loop: { trail, hours, milestones },
```

적용 순서: base → hill/ridge → trail → crest → flat → pad (뒤가 이김).

### 렌더링

- **지형 메시**: 직접 만든 격자, **부드러운 법선** (면마다 윤곽선 방지). 색은 높이별 흙빛 팔레트 + 표면 색 텍스처
- **정보 패스**: 지형 전용 정보 셰이더 (`userData.infoMaterial`). 조각마다 문자세트 선택
  - 높이 띠: TERRA_LOW (<6m) / MID (6~14m) / HIGH (>14m), 경계는 디더링
  - 표면 마스크 (트레일/아스팔트/연석) 가 있으면 그 문자세트 우선
  - **등고선은 정보 패스에서 방향까지 계산** (1칸 두께 선은 Sobel로 방향을 못 구함)
  - 알파 인코딩: `<64` 일반 문자세트 · `64~127` 지형 (윤곽선 약하게) · `≥128` 선 (방향 0~3)
- **글자 셰이더**: 지형 법선은 윤곽선 계산에서 가중치 0.35 → 언덕 면엔 선 없고 **능선 실루엣만 선**. 등고선은 윤곽선보다 어둡게
- **`pastel` 값**: 지금은 색을 최대 채도로 만들어서 흙색이 형광이 됨 → `mix(hue, 흰색, pastel)` (낮 0.35, 밤 0.1)
- **`edgeGain`**: 밤에 윤곽선 밝기 낮춤
- `MAX_SETS` 16 → **32**

### 지형 위 차 물리 (아케이드 유지)

- `ArcadePhysics({ bounds, terrain })` — 지형 미지정 시 평지 → 기존 테스트 그대로 통과
- 차 상태 추가: `y, vy, pitch, roll, airborne` (+ 보간용 이전값)
- 바퀴 4점 높이 샘플 → 차 높이 + 앞뒤/좌우 기울기
- 경사 중력: 오르막 감속, 내리막 가속
- **공중 상태**: 볼록 지형을 빠르게 넘으면 자동으로 뜸 → 중력 낙하 → 착지 (세게 떨어지면 감속). 공중에서 조향/가속 20~30%. **점프대 따로 없이 지형 모양만으로**
- 충돌체에 바닥 높이 추가 → 점프로 낮은 물체 넘기 가능
- 중력 값은 아케이드 느낌 위해 조정 가능한 상수로 (9.81 ~ 20)
- Rapier 단계: 같은 높이 배열로 heightfield 충돌체 생성, 레이캐스트 차량이 공중/기울기 코드 대체. 인터페이스는 그대로

### 카메라

- `src/render/camera.js` 로 분리
- **높이 추종**: 차 아래 **지면 높이**를 부드럽게 따라감 (점프 시 화면 안 튐)
- **진행 방향 미리보기**: 속도 방향으로 최대 6m 앞을 봄 → 남쪽 주행 시야 9m → 15m
- **가림 회피**: 차~카메라 사이 지형이 시선보다 높으면 카메라를 자동으로 올림 (드물게 발생)
- 안개 25→75, far = 85 유지

### 낮/밤

- `src/render/timeOfDay.js`: 새벽/낮/노을/밤 키프레임 보간 → 태양 방향·색, 하늘광, 안개, 노출, 밝기 하한
- 그림자 흔들림 방지: 태양 방향 0.5° 단위로만 갱신. 고도 5° 미만이면 그림자 끄고 달빛으로
- **헤드라이트**: SpotLight 1개, 그림자 없음. **처음부터 씬에 두고 밝기만 0↔N** (라이트 개수 바뀌면 셰이더 전체 재컴파일 → 프레임 끊김)

### 배치

- 소품 높이 = 바닥 4모서리 중 최저 높이 - 0.1 (뜨는 것 방지). 인스턴싱 영향 없음
- 나무는 수직, 바위는 지면 법선 방향
- 자동 배치 시 급경사/길 위 거부
- 구역 패드는 자동으로 지형 평탄화

### 성능

지형으로 추가되는 것: 그리기 3회 (패스당 1) + 텍스처 2장 (각 ~0.4MB). 목표 유지: 패스당 그리기 <150, CPU <4ms.

## 9. 구현 순서

**단계 B — 지형** (각 단계 테스트/육안 확인 가능)
1. `terrain.js` 순수 모듈 + 테스트 (같은 시드 = 같은 결과, 패드 평탄, 격자 경계 연속)
2. 지형 메시로 바닥 교체 → 언덕 보임 (차는 아직 높이 0이라 파묻힘)
3. 차 높이/기울기 + 카메라 높이 추종·미리보기 → 언덕 넘을 때 바퀴가 지면에 붙음
4. 지형 정보 셰이더: 높이별 문자세트, `MAX_SETS` 32, 지형 윤곽선 약화, `pastel` → 언덕 면엔 선 없고 능선만
5. 등고선 → 단색 모드에서 지형도처럼 읽힘
6. 경사 중력 + 공중 상태 + 언덕 점프 → 테스트 + 육안
7. 표면 텍스처 + 표면별 주행감 + 트레일 경계선 → 흙길/잔디 속도 차이 테스트
8. `map.js` 지형/트레일 + 배치: 패독, HQ, 1번 능선, 구름바다, 트랙 리밋, E→G 키 이동
9. 카메라 가림 회피 + 디버그 오버레이 (높이, 표면, 충돌체, 그리기 횟수)

11. HUD 텔레메트리 + 방향 테이프
