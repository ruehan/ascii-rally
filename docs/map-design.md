# ASCII World — 맵 설계 v1

레벨 디자인 + 기술 구조 검토 결과 통합본. 구현 전 확정용.

## 1. 테마: `~/` — 운전해서 돌아다니는 파일시스템

세상 = 홈 디렉터리. 구역 = 폴더, 도로 = 경로, 랜드마크 = 기본 도형으로 만든 **거대한 ASCII 글자**.
문자로 그린 세상 안에 문자 조형물 → 렌더러와 테마가 자연스럽게 맞음.

| 구역 | 경로 | 역할 |
|---|---|---|
| 시작점 | `~` | 인트로, 조작법 |
| 허브 | `/` | 중앙 교차로, 안내판 |
| 소개 | `/about` | 자기소개 |
| 프로젝트 | `/projects` | 3~6개 전시 |
| 기술 | `/skills` | 기술 스택 |
| 연락처 | `/contact` | 메일, GitHub 등 |
| 놀이터 | `/tmp` | 경사로, 상자 더미 (물리 단계에서 활성) |
| 이스터에그 | `/dev/null` | 빠지면 화면 글리치 후 시작점 복귀 |
| 경계 | EOF 바다 | vim 빈 줄 `~` 로 채운 바다 |

HUD 프롬프트 = 현재 위치 표시: `guest@folio:~/projects$`
구역 이름/모양은 `map.js` 설정만 바꾸면 교체 가능.

## 2. 전체 지도 (위에서 본 모습)

좌표: Three.js XZ, 미터. -Z = 북쪽(출발 시 정면). 대략적 스케치.

```
 x→   -100        -60        -20   0   20         60        100
z=-100 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  EOF 바다 (r>100)
 -88   ~                        .-( T )-.                      ~  T = 회차 지점 r8
 -78   ~                   [P3]====|====[P6]                   ~
 -64   ~                   [P2]====|====[P5]       (o) /dev/null ~  (70,-60)
 -50   ~                   [P1]====|====[P4]                   ~  프로젝트 패드 x=±11
 -44   ~      /tmp               [ ]|[ ]   <- 입구 "[ ]"       ~
 -42   ~     (* PLAY)    .  -  -  -  +  -  -  -  .             ~  순환도로 r=42, 폭 7
 -32   ~       (-42,-42)/          |             \            ~
 -16   ~             /             |              \           ~
   0   ~  (@ ABOUT)==+=====( / HUB )=====+==(# SKILLS)         ~  동서 도로 z=0
       ~   (-58,0)    \       (0,0) r9   |   /  (58,0)         ~
  16   ~               \           |    /                     ~
  32   ~                \          |   /  (^ CONTACT)          ~
  42   ~                  ' -  -  -+-  '     (42,42)           ~
  50   ~                   >_      |                           ~  프롬프트 조형물 (-8,52)
  58   ~                     ( ~ SPAWN )  차 (0,62) 북쪽 향함  ~
 +100  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  주행 가능 r=100
```

**도로**: 남북 간선 x=0 (z +62 → -88, 폭 8) · 동서 도로 z=0 (x ±58) · 순환도로 r=42 (폭 7, 한 바퀴 ~22초) · `/tmp`, `/contact` 로 가는 대각 지선.

| GROUND (변경) | `` .,'` `` | 더 성기게, 조용한 여백 |
| ROAD (신규) | `` .:-= `` | 도로 |

| TILDE (신규) | `` ~≈ `` | EOF 바다 |
| CHEVRON (신규) | `` >» `` | 도로 위 방향 화살표 |

## 4. 동선과 길찾기

**카메라 제약 (실측)**: 고정 카메라 → 앞(북쪽) ~22m, 뒤(남쪽) ~9m, 좌우 ±16m 만 보임.
→ **멀리 있는 랜드마크로 길찾기 불가.** HUD + 바닥 표시로 안내해야 함.

**추천 첫 순회 (시계 방향, 정차 없이 70~90초)**:
시작점 → 북쪽 허브 → 서쪽 `/about` → 순환도로 북동쪽(`/tmp` 지나감) → 프로젝트 거리 북상 → 회차 → 남하 → `/skills` → `/contact` → 시작점

구역 간 이동 3~4초 (현재 최고속도 12.7m/s ≈ 46km/h 기준).

**규칙**
- **북쪽 우선**: 중요한 건 진행 방향 북쪽에. 남쪽으로 달리는 구간(시야 0.7초)은 넓고 비워둠.
- **길찾기 도구**: ① HUD 현재 경로 ② 화면 가장자리 화살표 `<- /about 34m` ③ 교차로 바닥 CHEVRON 화살표 ④ 표지판 ⑤ `M` 미니맵(선택) ⑥ 1.5초 정지 시 카메라 줌아웃(1.6배)
- **글자 라벨**: 3D 글자는 2m 미만이면 안 읽힘 → HTML 텍스트를 화면에 투영 + 글자 칸에 맞춰 정렬.
- **패널 열기**: 구역에 들어가면 HUD만 갱신. **패드 위 0.8초 정차** 시 패널 열림(테두리 GOLD 고리가 진행 바 역할). **E 키**로 즉시 열기도 가능. 열려 있는 동안 운전 입력 차단, Esc 로 닫기.

## 5. ASCII 가독성 규칙

1. **최소 두께 0.6m**. 랜드마크 폭 3m+, 높이 4~8m. 8m 넘으면 화면 위로 잘림.
2. **가림 규칙**: 높이 h 물체가 도로 남쪽 h m 이내면 차를 가림 → 높은 건 도로 북쪽/옆에. 또는 차와 카메라 사이에 오면 반투명.
3. **대비는 밝기로**: 바닥 < 0.25, 도로 ≈ 0.35, 물체 > 0.5, 랜드마크 > 0.7. 단색 모드에서도 모든 구역 구분돼야 함.
4. **평평한 무늬는 윤곽선 안 생김** → 도로 가장자리에 낮은 연석(0.25m), 패드는 0.15m 올림.
5. **각진 도형** (flatShading, 세그먼트 6~10). 매끈한 구는 뭉개짐.
6. **구역마다 대표색 하나**. 바닥도 같은 색을 어둡게 → 컬러 모드에서 은은하게 빛남. 중요한 물체에 회색 금지 (흰색 되어 윤곽선과 섞임).
7. **조형물은 남쪽(카메라 쪽)을 향하게**. 세운 토러스 = `O` 로 읽힘.

## 6. 기술 구조

### 맵 데이터: `src/world/map.js` (JS 데이터 모듈)

코드로 편집, diff 리뷰 가능, Vite 즉시 반영. glTF는 나중에 특정 랜드마크 모델용으로만.

```js
export default {
  bounds: { type: 'circle', r: 100 },
  spawn: { pos: [0, 62], rot: 0 },
  roads: [{ points: [[0, 62], [0, -88]], width: 8, charset: 'ROAD' }],
  zones: [{
    id: 'about', path: '/about', title: 'ABOUT', hue: '#4dd9e8',
    pos: [-58, 0], trigger: { type: 'circle', r: 13 }, exitPad: 2,
    landmark: 'glyphAt',
    pads: [{ pos: [0, 6], content: 'about' }],
    props: [{ kind: 'tree', pos: [-5, -8], scale: 1.2 }],
  }],
  scatter: [{ kind: 'tree', count: 120, seed: 42, avoid: ['roads', 'zones'] }],
};
```

소품 종류(kind)는 레지스트리에 기본값(모양, 재질, 문자세트, 충돌체, 그림자) 정의, 개별 항목에서 덮어쓰기.

### 파일 구조

```
src/
  main.js                 조립만
  core/    loop.js (고정 60Hz), input.js, events.js (이벤트 버스)
  render/  ascii.js, charsets.js, lighting.js, camera.js
  world/   map.js, build.js, roads.js, scatter.js, props/registry.js, materials.js, geometries.js
  physics/ shapes.js (공용 충돌체), arcade.js (현재 방식 + 공간 해시), rapier.js (나중)
  vehicle/ car.js (외형만), controller.js (입력 → 가속/조향)
  zones/   zoneSystem.js (진입/이탈 이벤트, DOM 접근 없음)
  ui/      panel.js, prompt.js, hud.js, router.js (#projects/foo 딥링크)
  content/ about.js, projects/*.js, skills.js, contact.js
```

렌더러 ↔ UI 분리: 구역 시스템은 이벤트만 보냄, UI 모듈이 받아서 DOM 처리.

### 맵 만들기 전 필수 수정 (현재 코드 문제)

| # | 문제 | 수정 |
|---|---|---|
| A | 물체마다 재질/모양 따로 생성 → 소품 300개면 그리기 600회+ | 공용 재질 팔레트 + InstancedMesh |
| B | 정보 패스 셰이더가 인스턴스 위치 무시 → A 적용 시 문자세트/윤곽선 깨짐 | 셰이더에 `instanceMatrix` 반영 |
| C | 정보 패스가 매 프레임 씬 전체 순회 + 재질 교체 | 목록 캐시, 재질 단위 매핑 |
| D | 문자 세트 8개 꽉 참 | 16개로 확장, `charsets.js` 로 분리 |
| E | 그림자 과함 (2048², 소프트, 매 프레임 흔들림) | 1024², 범위 ±28, 텍셀 단위 스냅 |
| F | 카메라 원거리 200 (안개는 75에서 끝) | `far ≈ 85` |
| G | 원형 충돌만, 동시 충돌 시 두 번 튕김, 경계 하드코딩 | 원+사각 충돌, 공간 해시, `map.bounds` 사용 |

나중으로 미룸: 화면 셰이더 최적화(칸 단위 패스), MRT, 모바일 대응.

## 7. 구현 순서

**단계 A — 기반 정리** (화면 변화 거의 없음)
1. 잔손질: 카메라 far, 그림자, 프레임마다 객체 생성 제거 (F, E)
2. `charsets.js` 분리 + 16개 확장 + 신규 세트 (D)
3. 인스턴싱 대응 정보 셰이더 (B)
4. 공용 재질/모양 + 정보 패스 캐시 (A, C)
5. 충돌체 공용화 + 공간 해시 + 맵 경계 (G)
6. 고정 시간 간격 루프 + 차 분리 (컨트롤러 / 외형)

**단계 B — 맵 구축**
7. 소품 레지스트리 + `map.js` + `build.js`
8. 도로 + 연석 + EOF 바다 경계
9. 허브 + 5개 구역 광장 + 글자 랜드마크
10. 디버그 오버레이 (충돌체/트리거 표시, 그리기 횟수)

**단계 C — 상호작용**
11. 구역 시스템 + 이벤트 버스
12. HUD 프롬프트 + 화면 가장자리 화살표
13. 패드 정차 → 패널, 딥링크, 텍스트 전용 목록 보기 (접근성/SEO)

**단계 D — 다듬기** (이후)
14. 표지판 라벨, 정차 시 줌아웃, 미니맵
15. 물리 엔진 (Rapier) → `/tmp` 놀이터 활성화
16. `/dev/null`, 테마 전환, 사운드, 터치 조작, 배포

**성능 목표**: 패스당 그리기 150회 미만, 프레임당 CPU 4ms 미만, 모바일 DPR 1.5에서 60fps.
