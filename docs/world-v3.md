# Stage ~/ — 월드 v3 (1.2 km × 1.2 km)

레벨 디자인 + 엔지니어링 검토 통합본. 이전 설계는 `map-design.md`.

## 원칙
- **홈(±200)은 좌표 그대로** — SS1~SS5 from/to·목표 기록 유지. 새 지역은 홈을 둘러싼 고리.
- 카메라 = 추격 시점(차 뒤 16 m/위 16 m, 고속에서 후퇴). 바다는 북쪽 유지.
- 실제 차량 성능 기준: 코너 반경 ≥10 m(서킷), 랠리 헤어핀 7~9 m, 크레스트는 직선에만(착지 후 ≥60 m), 소품은 도로 끝 ≥2 m(고속 ≥4 m).
- **고속 아스팔트(GP·롱 스트레이트·해안)**: 340 km/h에서 종단 곡률 반경 < ~740 m 볼록 구간은 차가 뜸 → smooth ≥120, maxGrade ≈0.03~0.06, 크레스트 없음.
- 실명/상표 금지. "르망", "뮐산" 등은 문서 안 비유로만.
